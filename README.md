# COMP3011J Mobile Computing  
# Android Application Term Project


## Project Overview

This repository contains the Android application project developed as part of the **COMP3011J Mobile Computing** module.

The objective of this project is to design, implement, and evaluate an Android application that solves a meaningful problem and demonstrates effective use of Android development technologies.

The project should demonstrate the ability to:

- Analyse a problem and identify a suitable mobile solution
- Design and implement an Android application
- Apply appropriate programming and software engineering practices
- Develop a useful and well-designed application for users


A strong application should demonstrate integration between the following four main aspects:

1. **Data Input**
2. **Data Processing**
3. **Data Storage**
4. **Data Output / User Interface**

These components should work together to provide meaningful value to the user.

# Team Collaboration Guidelines

To ensure effective teamwork:

- Divide tasks clearly between team members.
- Commit changes regularly throughout development.
- Use meaningful commit messages.
- Document important development decisions.
- Maintain communication and coordination within the team.
- Ensure that every team member contributes throughout the project lifecycle.


Examples of meaningful commit messages:

Good:

```
Add user authentication screen
Implement database connection
Fix RecyclerView display issue
```

Avoid:

```
update
test
final
changes
```

# Application Development Requirements

The application should demonstrate the following:


## 1. Data Input

The application should obtain useful information from appropriate sources.

Examples:

- User input
- Forms
- Images
- Camera
- Location services
- Sensors
- External APIs
- Device information


Consider:

- Is the input process intuitive?
- Is validation implemented?
- Can users easily correct mistakes?


---

## 2. Data Processing

The application should provide meaningful processing beyond simply collecting and displaying information.

Examples:

- Searching
- Filtering
- Sorting
- Calculations
- Recommendations
- Classification
- Data analysis
- Notifications
- Personalisation
- AI-assisted processing where appropriate


The processing should provide clear added value to the user.


---

## 3. Data Storage

The application should use suitable storage solutions depending on project requirements.

Possible approaches:

- Room Database
- SQLite
- DataStore
- Local files
- Cloud databases
- Backend services
- External storage solutions


Students should consider:

- What data needs to be stored?
- How data is retrieved and updated?
- Data security and privacy considerations


---

## 4. Data Output and UI/UX

The application should present information clearly and effectively.

Examples:

- Screens
- Lists
- Cards
- Charts
- Maps
- Notifications
- Dialogs
- Interactive components


The design should consider:

- Navigation
- Layout consistency
- User experience
- Accessibility
- Different screen sizes
- Error handling
